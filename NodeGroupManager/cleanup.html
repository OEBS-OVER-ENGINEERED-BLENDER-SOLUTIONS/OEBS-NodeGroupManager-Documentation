08 · Batch & cleanup

Selection Tools

Appears as Selection Tools (N) where N is the number of checked rows.

  • Remove — delete all checked groups at once.
  • Export — write the checked groups to an external .blend.
  • Fake ON / Fake OFF — set Fake User on every checked group.
  • Mark Asset — mark the active group as an asset.

09 · Batch & cleanup

Cleanup & Batch

Node Editor surface only.

  • Scan Unused Sockets — file-wide report of groups with dead interface sockets.
  • Versions — lists all version-tagged groups.
  • Remove Orphaned — deletes every unused group (Fake User respected).
  • Remove All — deletes every group of the current type (confirmation required).
  • Batch Rename — bulk rename by prefix / suffix / find-replace across the current type.

10 · Batch & cleanup

Diagnostics

This section appears only when stray objects exist. It reports the count and offers Delete Stray Groups (groups used only by stray objects) and Delete Stray Objects (objects in no collection).

Why it mattersStray objects are a common reason a group appears to be in use when nothing in your scene references it.

11 · Batch & cleanup

Import & Exchange

  • Import .blend — append node groups from an external file.
  • Cross-File Search — search every .blend in your Library Folder by name and import matches.
  • Hot Swap — the Quick Switch popup (searchable jump to any group; also bindable to a hotkey).
  • Team Export — write a manifest of every group (name, type, version, node/link counts, complexity, parents, children, flags) as JSON or CSV.
